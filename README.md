# tutora-legal

Javne pravne i informativne stranice za aplikaciju Tutora.

## Stranice

- `index.html` – početna stranica
- `privacy.html` – Politika privatnosti
- `terms.html` – Uvjeti korištenja
- `support.html` – korisnička podrška
- `delete-account.html` – upute i web-zahtjev za brisanje računa

Stranice su statične i namijenjene objavi putem GitHub Pagesa.
